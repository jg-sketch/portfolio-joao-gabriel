# 💻 Portfólio — João Gabriel Hermida Martins

Portfólio pessoal desenvolvido para apresentar minha trajetória, habilidades, projetos e conhecimentos na área de desenvolvimento de software.

O projeto foi construído com foco em um design moderno, limpo, responsivo e acessível, utilizando tecnologias web fundamentais.

---

## 👨‍💻 Sobre o projeto

Este portfólio foi desenvolvido como uma forma de apresentar meus conhecimentos e projetos de maneira profissional, além de servir como um espaço para acompanhar minha evolução como desenvolvedor.

O site apresenta:

- 👋 Apresentação pessoal
- 📚 Habilidades e conhecimentos técnicos
- 💻 Projetos desenvolvidos
- 🐙 Links para meus repositórios no GitHub
- 💼 Perfil do LinkedIn
- 📧 Contato por e-mail
- 🌙 Modo claro e escuro
- 📱 Layout responsivo para dispositivos móveis

## ✨ Funcionalidades

### 🌙 Dark Mode

O portfólio possui um sistema de alternância entre modo claro e escuro.

A preferência do usuário é armazenada no `localStorage`, permitindo que o tema escolhido seja mantido mesmo após fechar e abrir o site novamente.

### 📱 Responsividade

O layout foi desenvolvido para funcionar em diferentes tamanhos de tela, incluindo:

- Computadores
- Notebooks
- Tablets
- Smartphones

### 🧭 Navegação

O site possui navegação por seções:

- Sobre
- Habilidades
- Projetos
- Contato

Também possui menu adaptado para dispositivos móveis.

### ✨ Animações

Foram adicionadas animações sutis de entrada dos elementos utilizando `IntersectionObserver`, respeitando também a preferência do usuário por redução de movimento.
