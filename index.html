Sobre mim

Sou o João Gabriel, natural de Niterói e atualmente construindo minha base como desenvolvedor web. Trabalho com HTML5 e CSS3 para estruturar e estilizar páginas, e uso JavaScript para dar interatividade a elas — incluindo manipulação do DOM, que é a parte que mais gosto de praticar.

Também estudo C#, Java, Python e bancos de dados relacionais (SQLite e MySQL), o que me ajuda a entender lógica de programação e estruturação de dados além do front-end.

Prefiro aprender construindo: cada projeto deste portfólio nasceu de uma necessidade real de praticar um conceito específico, do zero, sem frameworks.
